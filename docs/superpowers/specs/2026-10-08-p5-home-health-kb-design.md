# P5 家庭用药安全知识库 设计规格

调研依据：`docs/research/2026-10-08-p5-home-health-kb-research.md`
承接：P4 设计规格第 1 节「非目标」中「自建 OTC 小知识库（后续项）」

## 1. 目标与非目标

### 目标
- 为智能体增加一个**家庭常备药安全小知识**知识源，回答「用药安全」类问题：剂量上限、常见不合理联用、特殊人群禁忌、需要就医的红旗症状。
- 完全**复用 P4 已建成的资产**：`EvidenceEntry` 数据模型、`assets/data/evidence_kb.json`、`scripts/import_knowledge.py` 导入管线、`KnowledgeIndex` BM25 检索、智能体工具注册框架。
- 每条结论**强制带出处**（国家卫健委 / NMPA 说明书范本），可核验。
- 离线可用，零网络依赖（与 P4 循证库一致）。

### 非目标
- **不做处方建议**：不针对个人病症「开方」，不推荐具体药物组合。
- **不做诊断**：不判断病情，不替代医生/药师。
- **不做儿童/孕产/慢病具体剂量换算**：仅给出「遵医嘱/遵说明书/按体重由专业人员指导」的引导。
- **不接外部药品数据库**：不接入 DrugBank 等（许可/合规原因），不写爬虫。
- 不做药品库存/提醒/交互（后续可另立）。

## 2. 现状与差距

### 已有基础（P4 交付）
- `lib/models/evidence.dart`：`EvidenceEntry{id, domain, condition, topic, recommendation, evidenceLevel, source, url, license}`，含 `fromJson/toJson` 与证据强度排序。
- `scripts/import_knowledge.py` + `scripts/knowledge_sources/*.json`：种子 → 归一 → 校验 → 输出 `assets/data/evidence_kb.json`。
- `knowledge_engine.dart`：`KnowledgeIndex.build()` 已支持 evidence 源（`source:'循证库'`）参与 BM25，`alwaysSearch` 语义。
- `agent_service.dart`：工具注册 + schema + switch 分发 + `_clip()` 限长 + `_toolLabels`；现有 13 个工具。

### 差距
- 现有 evidence 库覆盖「运动/营养」的**循证医学**结论，缺少**家庭用药安全**维度。
- 无「安全提示」类内容结构与对应检索工具。
- 缺少用药场景的强免责与就医引导话术规范。

## 3. 架构（复用式扩展）

```
NMPA 说明书范本 + 卫健委参考表
        │  人工摘录改写（无爬虫）
        ▼
scripts/knowledge_sources/otc_safety_seed.json   ← 新增种子
        │  import_knowledge.py（复用）
        ▼
assets/data/evidence_kb.json  →  新增 otcSafety[] 数组
        │  KnowledgeIndex.build()（复用，新增安全源）
        ▼
agent_service.dart  →  新增工具 search_otc_safety
        │
        ▼
智能体回答「用药安全」问题 + 强制出处 + 强免责
```

关键决策：**不新建独立管线**。安全条目复用 `EvidenceEntry`，`domain` 取 `用药安全`，`evidenceLevel` 取 `指南`（官方文件）或 `专家`（说明书）；仅在 `evidence_kb.json` 内新增一个 `otcSafety` 数组以区分来源，`KnowledgeIndex` 将其编入同一索引（`source:'用药安全'`）。

## 4. 知识内容范围（首批）

依据调研 §3，首批覆盖 8 组、约 60~80 条：

| 分组 | 条目要点 |
|---|---|
| 退热镇痛 | 对乙酰氨基酚（2g/天上限、忌联用复方、忌酒、肝病慎用）、布洛芬（餐后服、消化道溃疡禁用、孕妇避免）、阿司匹林（不作退热首选、儿童避免） |
| 中成药退热 | 与对乙酰氨基酚/布洛芬不可联用；风寒不适用；非预防用药；同类不联用 |
| 咽痛 | 地喹氯铵含化、六神丸孕妇禁用且忌地高辛、清咽滴丸忌温补 |
| 止咳化痰 | 化痰药忌联用中枢镇咳药；哮喘忌乙酰半胱氨酸；相关禁忌人群 |
| 干咳 | 福尔可定/右美沙芬中枢镇咳，哮喘痰多慎用，孕哺及精神病史禁用 |
| 鼻部症状 | 抗组胺致困倦禁驾驶/高空；减充血剂反跳性鼻出血与禁用鼻炎 |
| 恶心呕吐 | 桂利嗪镇静叠加；藿香正气水含醇、忌头孢（双硫仑）、含生半夏 |
| 用药安全通识 | 常见不合理联用表、特殊人群（老幼孕）用药原则、服药前读说明书与咨询专业人员 |

每条结构：`topic`（药名/场景）、`recommendation`（改写后的安全提示）、`source`（国家卫健委/NMPA）+ `url`、`license`（官方公开发布）。

## 5. 安全与合规设计

1. **强免责**：工具返回与智能体话术末尾固定附「本内容为用药安全常识，不能替代医生或药师的诊断与处方；具体用药请阅读说明书并咨询专业人员」。
2. **红旗症状引导就医**：命中「高热不退、呼吸困难、意识改变、严重过敏、呕血黑便」等关键词时，优先输出就医提示。
3. **人群保护**：涉及儿童、孕妇、哺乳期、老年人、慢病（肝/肾/消化道）时，只输出「禁用/慎用/须遵医嘱」结论，**不给具体剂量**。
4. **不做组合推荐**：只回答「能不能一起用/为什么不能」，不回答「应该用哪几种」。
5. **出处强制**：任何安全结论必须带来源；检索不到时明确回答「本地库暂无该药品安全信息，请咨询药师」，绝不编造。
6. **写入 system prompt**：新增「用药安全原则」条款，禁止诊断、禁止处方、禁止编造剂量。

## 6. 智能体工具设计

新增 1 个工具：

```
search_otc_safety(query: string, topic?: string)
```
- `query`：用户问题关键词（药名、症状或「XX和YY能不能一起吃」）。
- `topic`：可选，限定分组（退热镇痛/止咳/鼻部/胃肠/外用/通识）。
- 返回：按证据强度排序的安全提示列表，**每条带 source + url**；附固定免责声明。
- 未命中：明确「本地库暂无相关安全信息，建议咨询药师」，不返回空编造。
- 复用 `_clip()`（≤2000 字符）与参数校验。

同时更新 system prompt 的证据引用规范，纳入「用药安全」来源与免责要求。

## 7. 验收标准

1. 问「对乙酰氨基酚一天最多吃多少」能返回 2g/天上限 + 出处 + 免责。
2. 问「布洛芬和阿司匹林能一起吃吗」能返回「增加胃肠道不适」等不合理联用结论 + 出处。
3. 问「藿香正气水和头孢能一起吗」能返回双硫仑反应警示 + 出处。
4. 问「孕妇能吃布洛芬吗」能返回「孕妇避免使用」等结论，且**不给具体剂量**，并引导咨询医生。
5. 命中红旗症状关键词时优先输出就医提示。
6. 检索不到的药名返回「本地库无该药安全信息，请咨询药师」，不编造。
7. 离线（断网）下工具完全可用（零网络）。
8. `flutter analyze` 零错误；`flutter test` 全量通过（新增用例全 fake 无网络）；Android release 编译通过。

## 9. 风险与缓解

| 风险 | 缓解 |
|---|---|
| 医药内容责任风险 | 只做安全提示、强免责、红旗引导就医、人群不给剂量、不做处方建议 |
| 说明书范本版权 | 改写而非照搬；官方公开发布文本；逐条标出处 |
| 内容时效性（药品警示更新） | 记录来源日期；README/文档注明「以最新说明书与医师意见为准」 |
| 误导性联想（把安全库当用药顾问） | 工具命名与话术统一为「安全常识」，首次使用给出边界说明 |
